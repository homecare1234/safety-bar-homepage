화장실 환풍기는 인터넷으로 사서 직접 바꾸는 분도 있습니다. 같은 크기 일반 환풍기를 그대로 바꾸는 일이라면 해 볼 만하지만, 전기와 천장 작업이 들어가니 시작하기 전에 어떤 일이 있는지 알아 두세요.

## 셀프 교체할 때 해야 하는 일

1. **전원 차단:** 환풍기는 전기에 바로 이어져 있습니다. 차단기를 내리고 작업해야 합니다.
2. **크기 확인:** 새 제품이 기존 천장 구멍에 맞는지 봅니다. 위 사진처럼 기존 것과 새것은 크기가 다른 경우가 많습니다.
3. **배기 덕트 연결:** 천장 안 배기 통로에 새 환풍기 배기구를 잇습니다. 틈이 생기면 공기가 천장 안으로 샙니다.
4. **전선 연결:** 기존 전선을 새 제품에 맞게 연결합니다.
5. **고정:** 천장에 단단히 고정해야 돌 때 덜덜 떨리지 않습니다.

## 업체에 맡기면 좋은 경우

- **복합환풍기로 바꿀 때:** 일반 환풍기보다 커서 천장 구멍을 넓혀야 하는 경우가 많습니다. 위 사진처럼 자를 자리를 표시하고 재단합니다. [화장실 복합환풍기 교체](/combo)
- **냄새 때문에 바꿀 때:** 댐퍼가 제대로 닫히게 달아야 냄새가 줄어듭니다. [화장실 환풍기 댐퍼](/damper)
- **전기 작업이 부담스러울 때**
- **천장이 높거나 사다리 작업이 불편할 때**

## 셀프 교체 vs 업체 교체

| | 셀프 교체 | 업체 교체 |
|---|---|---|
| 제품 고르기 | 크기·배기구 직접 확인 | 사진 보고 맞는 제품 안내 |
| 천장 재단 | 직접 | 업체가 작업 |
| 덕트·전기 연결 | 직접 | 업체가 작업 |
| 작동 확인 | 직접 | 휴지를 대어 흡입까지 확인 |
