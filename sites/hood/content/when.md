주방 후드는 요리할 때마다 기름 연기를 빨아들여서, 쓸수록 안쪽에 기름이 쌓이고 모터가 닳습니다. 몇 년이 지났는지보다 **지금 어떤 증상이 있는지**를 보는 것이 정확합니다.

## 교체 신호 5가지

**1. 잘 빨아들이지 않는다.** 요리 연기가 주방에 퍼지고 냄새가 오래 남습니다. 필터를 닦아도 그대로라면 팬과 모터까지 기름이 찬 것입니다. [주방 후드 기름때](/grease)

**2. 소리가 커졌다.** 웅웅 울리거나 덜덜 떨립니다. 팬에 기름이 붙어 무게가 쏠렸거나 모터가 닳은 것입니다. [주방 후드 소음](/noise)

**3. 기름이 떨어진다.** 후드 아래로 기름 방울이 떨어지거나, 후드 겉이 끈적합니다.

**4. 모터가 멈춘다.** 켜도 안 돌거나, 돌다가 멈춥니다. 타는 냄새가 나면 바로 끄고 쓰지 마세요. [주방 후드 모터 고장](/motor)

**5. 다른 집 냄새가 들어온다.** 후드를 끄고 있을 때 음식 냄새나 담배 냄새가 납니다. [주방 후드 냄새](/smell)

## 청소로 될 때, 바꿔야 할 때

| 증상 | 청소 | 교체 |
|---|---|---|
| 필터에 기름 | 됩니다 | - |
| 필터 닦아도 약한 흡입 | - | 필요 |
| 소리가 커짐 | - | 필요 |
| 모터 멈춤·타는 냄새 | - | 필요 |

필터 청소 방법은 [주방 후드 필터 청소 방법](/filter)에 있습니다.

## 바꾸는 김에 모양도

교체할 때 지금 모양 그대로 바꿀 수도 있고, 슬림형·침니형처럼 다른 모양으로 바꿀 수도 있습니다. [주방 후드 종류](/types)
