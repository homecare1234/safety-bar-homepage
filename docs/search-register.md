# 네이버·구글 검색 등록 안내 (Claude가 준호형에게 한 단계씩 읽어 주는 용도)

새 사이트가 **실제 주소로 열리고**, `site.ts`가 `launched: true`(정식 공개)일 때 한다.
시안(`launched: false`)이면 검색엔진을 막아 두었기 때문에 등록해도 소용없다. 먼저 공개부터 한다.

Claude는 **한 번에 한 단계씩** 안내하고 캡처를 받아 확인한다. 네이버·구글 화면은 한국어로 나온다.
`<주소>` = `https://<영어>.현명한홈케어.com` (site.ts의 url)

---

## 네이버 (서브도메인마다 따로 등록해야 한다)

> Claude는 searchadvisor.naver.com 을 열 수 없다(모든 브라우저 도구 차단). 준호형이 누르고, 캡처를 받아 다음 단계를 알려 준다.
> 주요 페이지 주소 목록: `sites/<사이트>/content/*.md` 파일 이름 → `<주소>/<파일 이름>` (확장자 없이).

네이버는 사이트마다 따로 평가하기 때문에 새 사이트를 만들 때마다 꼭 해야 한다.

### 1. 사이트 등록
1. https://searchadvisor.naver.com 접속 → 오른쪽 위 **로그인**(네이버 아이디) → **웹마스터 도구**
2. 위쪽 입력칸에 `<주소>` 입력 → 오른쪽 화살표(등록) 클릭

### 2. 소유확인
1. **HTML 태그** 를 선택
2. `<meta name="naver-site-verification" content="……" />` 같은 줄이 보이면 **그 줄 전체를 복사해서 Claude에게 붙여 넣기**
3. Claude가 할 일: `content="…"` 안의 값만 `site.ts` → `verification.naver`에 넣고 깃허브에 올린다
4. 준호형: Cloudflare에서 이 사이트 **다시 반영** (docs/cloudflare.md B)
5. 반영되면 네이버 화면으로 돌아가 **소유확인** 버튼 클릭 → «소유 확인이 완료되었습니다»

### 3. 수집 요청 (사이트 목록에서 방금 등록한 주소 클릭 → 왼쪽 **요청** 메뉴)
1. **사이트맵 제출** → `<주소>/sitemap-index.xml` 입력 → 확인
2. **RSS 제출** → `<주소>/rss.xml` 입력 → 확인
3. **웹 페이지 수집** → **자동**: Claude가 `node scripts/indexnow.mjs <사이트>` 실행(IndexNow, 네이버 공식 지원). 아래 수동은 필요 없음.
   (수동으로 할 때만) 메인 주소와 주요 페이지 주소를 하나씩 입력 → 확인
   (주요 페이지 주소 목록은 Claude가 `sites/<사이트>/content/` 파일 이름으로 만들어 준다)

### 4. 확인 (2~4주 뒤)
**리포트 → 검색 노출**에서 수집됐는지 본다. Claude에게 «네이버에 잘 나오는지 봐줘»라고 하면 된다.

## 구글

**현명한홈케어.com 전체가 이미 «도메인 속성»으로 등록돼 있어서** 새 사이트는 소유확인 없이 **사이트맵만** 내면 된다.

1. https://search.google.com/search-console 접속 (구글 로그인)
2. 왼쪽 위 속성 선택에서 **현명한홈케어.com** (또는 `xn--v42bo8r8ohbsg7xazl.com`) 선택
   - **목록에 없으면**: 이 속성이 원래 제작자 계정에 있다는 뜻. 원래 제작자에게
     «서치콘솔 **설정 → 사용자 및 권한 → 사용자 추가**로 내 구글 계정을 **소유자**로 추가해 달라»고 부탁한다.
3. 왼쪽 **Sitemaps**(사이트맵) → «새 사이트맵 추가» 칸에 **전체 주소** `<주소>/sitemap-index.xml` 입력 → **제출**
4. **URL 검사**(맨 위 검색칸)에 메인 주소 입력 → **색인 생성 요청** (선택, 빨리 나오게 하는 용도)
