# 네이버 블로그 글 올리는 법 (준호형용)

이 폴더의 글을 **복사해서 네이버 블로그에 붙여 넣기만** 하면 됩니다.

## 순서

1. 네이버 블로그 → **글쓰기**
2. 이 파일의 **제목**을 복사해 제목 칸에 붙여 넣기
3. **본문**을 복사해 붙여 넣기
4. 본문 중 `[사진: …]`이라고 적힌 자리에 휴대폰으로 찍은 시공 사진을 넣기
   (그 줄은 지우고 사진만 남기면 됩니다)
5. 맨 아래 **태그**를 태그 칸에 붙여 넣기
6. **발행**

## 지킬 것

- **일주일에 1~2개**면 충분합니다. 한꺼번에 많이 올리는 것보다 꾸준히가 중요합니다.
- 사진은 **직접 찍은 시공 사진**을 씁니다. 같은 사진을 여러 글에 돌려 쓰지 않는 게 좋습니다.
- 고객 얼굴, 집 주소, 동·호수가 사진에 나오지 않게 합니다.
- 글 맨 아래 홈페이지 주소는 꼭 남겨 둡니다.
- 새 현장을 다녀오면 Claude에게 «블로그 글 써줘 + 사진 몇 장, 어디서 무엇을 했는지»라고 말하면 같은 형식으로 새 글을 만들어 줍니다.
